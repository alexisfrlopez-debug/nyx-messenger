# v0.2.32 (versionCode 36) — PRÉ-RELEASE

Date : 2026-10-19
Base : v0.2.31 (157e00c)

## Plan de tests : la liste DÉPLOYÉE défile à l'intérieur de la carte

Retour terrain sur la v0.2.31-test (demande opérateur) : « la nouvelle
disposition de l'interface est très bien, juste la liste "plan de test" ne
se déroule pas alors je n'arrive pas à atteindre les cases d'en bas ».

La v0.2.31 avait REPLIÉ la carte par défaut (▶/▼) — l'écran principal est
compact — MAIS la liste DÉPLOYÉE reprenait sa pleine hauteur SANS aucun
scroll : en ouvrant la carte, les cases du bas retombaient sous le bord de
l'écran, inatteignables. C'est la cause exacte du retour.

### Correctif (TestPlanCard)
La liste d'items déployée est désormais **CONFINÉE** (`heightIn` max 260 dp)
avec un **`verticalScroll` interne** :
- toutes les cases + le bouton « Tout réinitialiser » restent atteignables
  quelle que soit la hauteur de l'écran ;
- l'entête (titre, consigne, progression X/N) reste visible au-dessus ;
- la carte repliée (défaut, v0.2.31) est inchangée ;
- la zone d'onglets garde sa place (fix weight(1f) v0.2.31 intact).

### Titre de la carte
`testplan_title` affiche enfin la version courante (il traînait à
« v0.2.26 » depuis trois releases) → « Plan de tests v0.2.32 ».

### Plan de tests renouvelé (11 items)
L'item **scroll-plan-tests** couvre ce correctif ; les 10 items v0.2.31
sont repris À L'IDENTIQUE (validation continue : aucun n'est encore coché
en terrain — onglets, clavier, verrou, console v0.8.2, appels, réplicas,
blocage + régressions).

### Rien d'autre ne change
Le code applicatif est celui de la v0.2.31 (aucun autre correctif) :
l'installation par-dessus ne requiert pas de désinstallation (même clé
release b0d17630…).
