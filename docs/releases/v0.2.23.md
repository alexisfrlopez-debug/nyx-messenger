## Contenu

### 1. Rendezvous signé (ADR-009 §3 → ADR-016) — toutes les versions
- **Asset embarqué** `assets/rendezvous.json` + `rendezvous.json.sig` : liste
  des réplicas d'amorçage signée ed25519 (clé de release dédiée HORS dépôt,
  clé publique compilée dans l'APK `RENDEZVOUS_PUBKEY`).
- **Signature sur les octets bruts** (`nyx-rendezvous-v1|` + fichier) — zéro
  canonicalisation JSON, vérification identique Python/Go/Kotlin.
- **Client** (`RendezvousList.kt`, pur, 10 tests JVM) : refus en bloc si un
  octet change ; onions normalisées avec checksum SHA3 validé (anti-injection) ;
  entrées invalides écartées une à une ; déduplication ; port conservé.
- **Fusion d'amorçage** : CUSTOM (test 2) > rendezvous signé > bootstrap
  legacy (v0.2.7 conservé en filet de sécurité) — logs `nyx-boot` distincts.
- **Serveur** : `GET /rendezvous` (envelope b64, non authentifié, servi en
  maintenance, 404 si non configuré) + `POST /admin/rendezvous` (console —
  signature vérifiée AVANT écriture atomique ; 409 si invalide, 400 sans
  pubkey) ; config `rendezvous` {file, pubkey} (`config.example.json` à jour).
- **Outillage** : `scripts/ed25519lib.py` (RFC 8032, 3/3 vecteurs KAT) +
  `scripts/gen_rendezvous.py` (keygen/make/sign/verify).
