# v0.2.54 — codec ADPCM négocié : APPELS AUDIO PC↔téléphone (interopération avec Nyx bureau v0.3.6)

**Date** : 2026-10-27 (session 76) · **Retour terrain opérateur** (verbatim) :
« les appels ne fonctionnent pas sur l'app windows » — levée du verrou codec
de l'exception documentée en v0.3.4 (session 74) : l'audio d'appel du bureau
exigeait un codec AAC que la JVM n'a pas.

## 1. Ce qui change

- **Nouveau codec logiciel ADPCM IMA 4-bit** (`p2p/Adpcm.kt`, miroir octet à
  octet du bureau) : 16 kHz mono ≈ 64 kbps (~8 Ko/s par sens — très en
  dessous de la capacité d'un circuit onion). Blocs fermes de 20 ms : une
  trame perdue ne corrompt jamais les suivantes.
- **Négociation `ac`** dans le protocole d'appel : le HELLO de l'appelant
  annonce ses codecs supportés (« aac,adpcm » pour ce téléphone ; « adpcm »
  seul pour le bureau ; ABSENT = téléphone ≤ v0.2.53 = AAC seul), l'appelé
  répond le codec CHOISI dans son ACCEPT.
  - **téléphone↔téléphone : AAC matériel INCHANGÉ** (l'appelé préfère
    toujours l'AAC quand l'appelant le supporte — aucune régression de
    qualité) ;
  - **PC↔téléphone : ADPCM dans les DEUX sens** — l'appelé téléphone bascule
    son émission (`switchSendingToAdpcm` — la boucle AAC s'arrête proprement,
    n'ayant encore rien émis, le micro est réutilisé) et sa réception
    (décodage logiciel sans MediaCodec) quand le pair est le bureau ;
  - un téléphone ≤ v0.2.53 qui appelle le PC reçoit un refus PROPRE avec
    message de mise à jour (jamais d'audio muet) ;
  - l'offre de signalisation porte aussi `ac` (informationnel — un pair
    ancien l'ignore).
- `CallAudio` : mode ADPCM complet (émission par blocs fermes, réception
  logicielle vers le AudioTrack, trame de taille inattendue ignorée sans
  dérive d'état) ; le csd-0 AAC CALCULÉ part toujours dans le HELLO/ACCEPT
  (un pair ancien configure un décodeur valide — jamais de crash).
- Tout le reste (messages, fichiers, invitations, accusés, visio
  téléphone↔téléphone, Tor embarqué, réplica embarqué) est **INCHANGÉ** —
  compatibilité complète v0.2.53 ↔ v0.2.54.
