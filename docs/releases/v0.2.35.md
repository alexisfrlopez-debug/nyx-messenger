# v0.2.35 (versionCode 39) — PRÉ-RELEASE

Date : 2026-10-22
Base : v0.2.34 (f91927e)

## TROIS CHANGEMENTS (demande opérateur, session 56)

### 1. FUSION — le réplica embarqué entre dans les versions NORMALE et TEST

Le RÉPLICA TEMPORAIRE EMBARQUÉ (v0.2.19 : « lorsque l'application est lancée,
le téléphone devienne lui-même un replica temporaire »), validé en version
« test 2 » de la v0.2.19 à la v0.2.34, est désormais **INTÉGRÉ AUX DEUX
versions** (normale et test) — demande opérateur : « je veux intégrer la
feature "replica embarqué" dans la version "normale" et la version "test 1",
et donc la version "test 2" n'a plus de raison d'exister ».

- `EMBEDDED_REPLICA` est **toujours vrai** (defaultConfig) ; le flavor
  `diag2` est **SUPPRIMÉ** : **2 APK par release** au lieu de 3 (standard +
  test) ;
- l'interrupteur Paramètres (carte « Réplica embarqué ») arrête/reprend le
  service — la table `replica_events` reste vide quand il est fermé ;
- l'annonce aux contacts, l'auto-ajout console (/admin/replicas) et le port
  80 de l'onion fonctionnent comme en « test 2 » — le téléphone devient
  joignable tant que l'app tourne ;
- `EmbeddedReplica` annonce désormais la version `0.2.35` (au lieu du
  littéral « test2 ») dans son profil public.

### 2. REFONTE ESTHÉTIQUE — « Nyx, déesse de la nuit », moins technique, plus agréable

Demande opérateur : « je veux modifier l'esthétique de l'application de
messagerie pour qu'elle soit moins "technique" et plus agréable, tout en
gardant la thématique "Nyx - déesse de la nuit" ».

- **Palette « Nuit de Nyx »** : indigo nuit profond en fond (dégradé vertical
  zénith → horizon), LUNE en or pâle comme couleur principale (boutons,
  actions), nébuleuse lavande en secondaire, jade tendre pour les états
  positifs (clin d'œil à l'ancien « vert oignon », adouci), rose crépuscule
  pour les erreurs. L'ancien couple violet nuit / vert olive (flat,
  « technique ») est retiré ;
- **Dégradé de ciel derrière TOUT l'app** (`NyxBackground` à la racine de
  MainActivity ; Scaffold/LockScreen transparents au-dessus) ;
- **Coins généreux** (cartes 18 dp, dialogues 24 dp) ;
- **Mode clair « aube »** (ivoire-lavendre) en remplacement du clair générique ;
- **Nouvelle ICÔNE** (lanceur) : croissant de lune or pâle + constellation sur
  ciel dégradé — l'app n'affichait plus l'icône par défaut du robot ;
- **Lune + constellation** en tête des écrans Connexion/Onboarding
  (`MoonHeader`) + tagline « La nuit protège vos conversations. » ;
- **Chaînes réchauffées** (12) : « Bootstrap du démon Tor… » → « Mise en place
  du réseau Tor… », verrou « Nyx garde vos conversations », thème
  « Nuit »/« Aube », Tor « Impossible de joindre le réseau Tor — vérifiez
  votre connexion… » etc. Les termes fonctionnels (Tor, onion, réplica) restent
  exacts — seul le ton change.

### 3. SERVEUR : constante de version ENFIN alignée (axe fiche, session 55)

`const version` de `cmd/nyx-server/main.go` passe de « 0.2.0 » (figée depuis
l'ORIGINE — constat session 55 : /admin/status ne distinguait pas un nœud
ancien d'un nœud à jour) à **« 0.2.35 »**. Après mise à jour du nœud, la
console affichera la version réelle. Le binaire
`nyx-server-linux-amd64-v0.2.35` est publié en asset de cette release
(rebuild déterministe, `/admin/replicas` ET `0.2.35` vérifiés dans les
strings).
