# Nyx v0.1.0 — premier APK autonome (historique)

> **Release conservée pour l'historique — contient un bug bloquant.** Utiliser
> la **v0.1.1** (ou ultérieure) : la création d'identité crashait sur
> Android ≤ 13 avec `SHA3-256 MessageDigest not available`.

## Contenu

- Premier APK entièrement autonome : installation en 1 clic, aucun service tiers.
- Tor embarqué (`libTor.so` — arm64-v8a, armeabi-v7a, x86, x86_64) : ni Orbot ni
  aucune dépendance externe (ADR-007).
- Natives embarquées ×4 ABI : libsodium (chiffrement), sqlcipher (base locale
  chiffrée), jnidispatch.
- APK universel unique, signé release (keystore dédié hors dépôt), R8 +
  shrinkResources, `allowBackup=false` — les clés d'identité ne quittent jamais
  l'appareil.
- Permissions fermées : INTERNET, ACCESS_NETWORK_STATE, FOREGROUND_SERVICE(+DATA_SYNC),
  POST_NOTIFICATIONS uniquement.
- Audit strict pré-build : PASSED (0 CRIT, 0 MAJOR, 4 MINOR documentés).
- Pipeline : `scripts/build-apk.sh` (audit → build signé → 13 contrôles
  d'autonomie → livraison).

## Bug connu

- Crash à la création d'identité sur Android 8 à 13 (SHA-3 absent du provider
  système). Corrigé en **v0.1.1** — voir sa release note.
