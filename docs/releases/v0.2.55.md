## 2. VISIO PC↔téléphone — MJPEG logiciel négocié (miroir bureau v0.3.7)

- `HELLO.vc` = codecs vidéo supportés de l'appelant (« h264,mjpeg »
  téléphone ; « mjpeg » bureau v0.3.7 ; ABSENT = H.264 seul ≤ v0.2.54) ;
  `ACCEPT.vc` = codec choisi (« mjpeg » seulement en MJPEG).
- **Téléphone↔téléphone : H.264 matériel INCHANGÉ** (champ vc absent du fil,
  format v0.2.20 octet pour octet — verrouillé par tests).
- Émission MJPEG : ImageReader YUV_420_888 → NV21 → `YuvImage.compressToJpeg`
  (q55, ~5 trames/s, gel si le circuit Tor ralentit) ; réception : JPEG →
  `BitmapFactory` → Canvas. `switchSendingToMjpeg()` bascule l'émission après
  l'ACCEPT d'un bureau (l'encodeur H.264 n'a rien émis — caméra ré-utilisée).
- Le bureau (v0.3.7) partage son ÉCRAN et affiche la caméra du téléphone.
