# Nyx v0.1.1 — correctif SHA-3 (création d'identité)

**Première release fonctionnelle.** Corrige le crash au premier lancement signalé
sur la v0.1.0 : la création d'identité échouait avec
`SHA3-256 MessageDigest not available`.

## Correctif

- **Cause** : `OnionCodec` (checksum des adresses onion) utilisait
  `MessageDigest.getInstance("SHA3-256")` — le provider système (Conscrypt) ne
  fournit SHA-3 qu'à partir d'Android 14, or l'application cible Android 8+
  (minSdk 26).
- **Solution** : implémentation SHA3-256 **FIPS 202 embarquée** via Bouncy Castle
  (`bcprov-jdk18on`, `SHA3Digest` — pas Keccak, padding `0x06`, calibré sur
  `golang.org/x/crypto/sha3` utilisé côté serveur Go). Plus aucune dépendance à
  la version d'Android : l'APK reste 100 % autonome (exigence §9.2).
- **Preuves** : 4 tests unitaires JVM verts (`OnionCodecTest`) — vecteurs NIST
  FIPS 202, vecteur checksum onion validé contre `hashlib.sha3_256` (Python),
  aller-retour base32, checksum invalide refusé.

## Livrable

- `nyx-v0.1.1-20261012-141434-release.apk` (22 Mo) — universel 4 ABI, signé
  release, Tor embarqué (`libTor.so` ×4 ABI), natives sodium/sqlcipher/jna ×4 ABI,
  zéro service tiers, `allowBackup=false`.
- versionCode 2 → **installable par-dessus la v0.1.0** (même signature de
  release), sans désinstallation ni perte d'identité locale.
- Audit strict pré-build : PASSED (0 CRIT, 0 MAJOR, 4 MINOR documentés).
